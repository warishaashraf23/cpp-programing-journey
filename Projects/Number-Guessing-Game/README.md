#  Number Guessing Game (C++)

A simple C++ console game where the computer generates a random number between 1 and 100, and the player tries to guess it.

## Features
- Random number generation
- Too High / Too Low hints
- Repeats until the correct guess

## Technologies
- C++
- iostream, cstdlib, ctime

## How to Run
1. Open 'main.cpp' in a C++ compiler.
2. Compile and run the program.
3. Start guessing!
