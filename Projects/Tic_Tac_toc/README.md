# Tic Tac Toe Game in C++

## Introduction
This project is a simple two-player Tic Tac Toe game developed using C++. Players take turns placing X and O on a 3×3 game board.

## Features
- Displays a 3×3 game board.
- Allows two players to play.
- Accepts positions from 1 to 9.
- Checks whether a position is already occupied.
- Detects the winner in rows, columns, and diagonals.
- Declares a draw if all nine positions are filled.

## Concepts Used
- 2D arrays
- Functions
- While loop
- If-else statements
- For loops
- User input and output

## How to Run
1. Compile the C++ program.
2. Run the program.
3. Enter a position between 1 and 9 when prompted.
4. Take turns until a player wins or the game ends in a draw.
